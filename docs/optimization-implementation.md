## 身份模块的处理范围

按要求删除 `identityMigration`、`InitializeIdentity`、历史默认企业常量及相关启动调用和迁移测试；不保留迁移标记表、旧索引转换、历史账号归属与角色转换逻辑。

保留当前模型的建表、默认管理员种子和企业预置角色初始化。用户名包含已删除账号在内全局唯一；新写入用户名、邮箱统一去除首尾空格并转为小写。

## 接入变化

- 工具链要求 Go 1.27.3；SQLite 构建需要 CGO 和 C 编译器。
- 运行时读取 `global.Config()`，请求使用 `global.RequestConfig(c)`；修改副本后用 `SetConfig` 发布，扩展配置用 `RegisterExtra`。快照和扩展配置中的对象均视为只读。
- 文件热更新仅支持 JWT 有效期与刷新窗口、CORS 和验证码配置。连接资源、路径、路由、安全策略等修改需要重启，文件写入成功并不代表当前进程已应用需要重启的设置。
- 跨域前端需要配置 Origin 白名单。Cookie 不允许脚本读取；HTTPS 反向代理需要显式设置 Secure 与可信代理。
- 普通请求上限默认 16 MiB，上传请求默认 32 MiB，编码开销包含在请求上限内；文件服务还校验实际写入字节数。
- `InitContext(ctx)` 支持上层取消，`Close()` 可重复调用，资源关闭错误会返回给调用方。`OnShutInit` 在请求及后台任务结束后执行，此时数据库等基础资源仍可用。
- `NewServiceGroup(db)` 绑定数据库服务；HTTP 默认装配、配置、IP 库等仍使用全局资源，尚不支持同一进程运行完全独立的多个应用实例。

## 验证与边界

本地验证环境为 macOS/arm64、Go 1.27.3：

| 验证 | 结果 |
| --- | --- |
| `go test -race -coverpkg=./... ./...` | 全量通过，未发现测试覆盖路径的数据竞争 |
| `go vet ./...` | 通过 |
| `go mod tidy -diff`、`go mod verify`、`git diff --check` | 通过 |
| 依赖版本复核 | 最终 95 个 require 声明均为各自模块路径最新版本 |
| `govulncheck -show verbose ./...` | 0 个调用路径漏洞、0 个导入包漏洞；仅有未使用的 `x/crypto/openpgp` 模块级公告，详见依赖报告 |
| `FuzzAESDecrypt`（5 秒预算、4 workers） | 30,120 次执行通过，未发现 panic |
| `BenchmarkCutterWrite`（Apple M4） | 3,785 ns/op，232 B/op，5 allocs/op；仅记录本次结果，无优化前基准，不能据此量化加速比例 |

真实 MySQL、PostgreSQL、Redis 测试由 `NAV_TEST_MYSQL_PORT`、`NAV_TEST_PGSQL_PORT`、`NAV_TEST_REDIS_ADDR` 启用。当前本机 Docker daemon 不可用，因此本地跳过这些用例；CI 已配置 MySQL 8.4、PostgreSQL 17、Redis 7.4 服务，尚未在远端运行此工作流。

AES 继续使用现有 CBC 协议，本次只修复输入校验及错误处理。改用随机 nonce 的 AES-GCM 需要同步调整客户端协议，仍属于后续工作。审计队列保证正常运行及优雅关闭时的排空，数据库写入失败会记录错误；进程崩溃持久性与事务 outbox 未在本次实现。认证路径仍实时读取身份及授权，未引入分布式权限缓存或宣称认证性能的量化提升。
